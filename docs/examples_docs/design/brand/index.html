Usage

  • Clear space: keep padding ≥ the tile's corner radius around the lockup.
  • Min size: mark 16px; lockup 120px wide.
  • Color: pine #0F766E on light, teal #2DD4BF on dark. Don't recolor per palette in the chrome — the brand mark stays pine/teal even when a user picks another UI palette.
  • Don't: stretch, add shadows/gradients, rotate, or place the pine mark on a busy/low-contrast background.
  • Favicon: favicon.svg (thicker pulse for legibility); export 32 & 16px PNG + ICO at build.
