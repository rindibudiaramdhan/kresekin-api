Usage

  • Clear space: beri ruang minimal setara tinggi handle tas di sekeliling mark atau lockup.
  • Min size: mark 16px; lockup 120px wide untuk layar kecil, 180px+ untuk header/dashboard.
  • Color: cyan #11BEC8, lime #C7EF4F, amber #FFB000. Jangan recolor brand mark mengikuti status atau role.
  • Background: gunakan lockup normal di surface terang; gunakan versi on-dark di sidebar/header gelap.
  • Don't: stretch, rotate, add drop shadow, put on busy images, or replace the smile accent with status colors.
